# Модели

В Git сохранены обученные классические модели и локальные Word2Vec/fastText, а также GloVe-поднабор. Подготовка: `python -m nlp_project.classical`. Разбиение и seed фиксированы. Предсказания и метрики хранятся отдельно в `reports/`, выбор — по validation macro-F1.

Для демонстрации UI используйте `reports/best_model.json`. Запускайте `python -m scripts.build_report` после новых экспериментов, чтобы обновить выбор. Приложение требуется перезапустить для сброса кэша.

BERT-веса и fine-tuned checkpoints исключены из Git; они появятся после успешного `python -m nlp_project.transformer`. На момент создания проекта загрузка BERT блокируется сетевой политикой. Случайная тестовая модель из unit-теста никогда не сохраняется здесь и не используется для анализа отзывов.

Joblib/Gensim-файлы загружают Python-объекты: используйте только доверенные файлы и версии из `requirements.lock`.
