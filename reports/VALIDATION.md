# Проверки текущего запуска

Все результаты относятся к текущей машине и зафиксированному корпусу, не к ещё не проверенному восстановлению среды в новой задаче.

| Проверка | Результат |
|---|---|
| SHA-256 исходного Amazon TSV | Совпадает с закреплённым источником |
| Полный classical workflow | Выполнен, 6 моделей, validation/test метрики и predictions сохранены |
| Повторный запуск `bash scripts/setup.sh` | Установка, проверка корпуса, обучение, отчёт и тесты завершились успешно |
| `python -m pytest -q` | **19 passed**, без skipped/failed |
| Unit-проверка Transformer-кода | Forward, обучение, сохранение checkpoint; временная случайная мини-модель только для теста кода, не для исследования |
| Streamlit AppTest | Пустой ввод и 5 контрольных текстов проверены |
| Реальный Chromium через Playwright | 5 ответов UI и 5 PNG; результаты в `ui_checks.json` |
| Jupyter execution | 9 notebooks выполнены; 8–10 не запускались из-за отсутствия pretrained-весов |
| Презентация | PPTX читается, 10 слайдов |
| Предобученный BERT | **Не загружен:** HTTP 403 от сетевого прокси для Hugging Face |
| Attention / frozen BERT / fine-tuning / BERT sweep | **Не выполнены**; реализация не выдаётся за результаты экспериментов |

Предупреждения: Streamlit 1.66.1 вызывает deprecated `pandas.DataFrame.reset_index(inplace=...)` в своём построителе диаграмм. Это предупреждение сторонней библиотеки; пять функциональных UI-проверок прошли. Веса и зависимости загружались с включённой проверкой TLS; GloVe-загрузчик сохраняет встроенную checksum-проверку.

Пятый контрольный отзыв с похвалой дизайну и жалобой на звук baseline ошибочно пометил позитивным. Это зафиксированный результат, не скрытый тестовый сбой. Контрольные тексты не предназначены для вычисления независимой accuracy.

Оставшееся действие: применить сохранённые сетевые требования в настройках облачной среды, опубликовать её, затем выполнить BERT-команды из README и обновить отчёт, notebooks и UI-скриншоты. Текущая работа не объявляется полностью завершённым BERT-исследованием.
